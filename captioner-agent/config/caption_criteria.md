# Caption criteria

These rules are for captions written by a vision model, which happens only
when an image has no PNG info. Captions taken from PNG info are the embedded
prompt with prompt syntax stripped, and are not rewritten.

Edit this file to change how captions are written. It is re-read for every
image, so changes apply without restarting the app.

## Format

- One caption per image, on a single line, in plain English.
- Aim for 15 to 40 words. Go shorter when the image is simple.
- Start with the main subject, then what it is doing, then the setting, then
  notable details such as clothing, colours, lighting and camera angle.

## Content

- Describe only what is visible in the image.
- State counts, poses, expressions, clothing, objects, setting and time of day
  when they are clear.
- Use left and right from the viewer's point of view.

## Do not

- Do not guess names of real people, artists or brands.
- Do not mention image quality, or say that the image is AI-generated.
- Do not use tag lists; write a sentence.
